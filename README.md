# ElleHacks Website

The React/Vite website for ElleHacks 2027.

## Prerequisites

- [Git](https://git-scm.com/downloads)
- [Node.js](https://nodejs.org/) 18 or newer, including npm

## Get the project from GitHub

Clone the repository and move into the website folder:

```bash
git clone https://github.com/ElleHacks/ElleHacks2027.git
cd ElleHacks2027/ellehacks-application-system
```

`node_modules` is not stored in Git. Install the dependencies locally from `package.json`:

```bash
npm install
```

## Run the website locally

Start the Vite development server:

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

To stop the server, press `Ctrl+C` in the terminal.

## Check your changes

Run the linter and production build before committing:

```bash
npm run lint
npm run build
```

## Commit and push new changes

Create a feature branch from the latest `dev-application-system` branch:

```bash
git switch dev-application-system
git pull origin dev-application-system
git switch -c your-name
```

After making and testing your changes, review and commit them:

```bash
git status
git add .
git commit -m "Describe your change"
git push -u origin your-name
```

Then open a pull request on GitHub from `your-name` into `dev-application-system`.

### Notes

- Do not commit `node_modules`; it is generated by `npm install` and should remain local.
- Replace `your-name` with your name. This will be your branch to work on and commit to.
- DO NOT COMMIT DIRECTLY TO MAIN OR THE DEV BRANCH!
